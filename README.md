# Portoin public website assets

Static resources used by https://portoin.my.id. This repository contains template UI images, fonts, and browser animation helpers; it contains no user uploads, CVs, account data, credentials, videos, or backups.

Production URLs are pinned to an immutable Git commit. Original copies remain on the Portoin origin for fallback. `asset-manifest.json` records file sizes and SHA-256 hashes.

Third-party fonts, libraries, and reference artwork retain their original copyright and licensing terms; no blanket license is granted for third-party artwork. Portoin-authored integration code is MIT licensed. Existing notices in distributed library files are retained.
